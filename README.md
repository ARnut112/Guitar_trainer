# Fret & Flow — ห้องฝึกกีตาร์

เว็บฝึกกีตาร์ภาษาไทยสำหรับจำโน้ตบนคอ ทำความเข้าใจรูปคอร์ด ฝึกฟังเสียง และเล่นฟิงเกอร์สไตล์ มีแผนฝึกประจำวัน บทเรียน เครื่องตั้งสาย และเมโทรนอม ใช้ได้ฟรีโดยไม่ต้องสมัครสมาชิก

## เปิดเว็บ

เปิดเว็บสาธารณะได้ที่ [https://arnut112.github.io/Guitar_trainer/](https://arnut112.github.io/Guitar_trainer/) หรือเปิด `index.html` ผ่านเว็บเซิร์ฟเวอร์ เช่น GitHub Pages, Laragon หรือ VS Code Live Server

ความก้าวหน้าและเป้าหมายบันทึกไว้ในเบราว์เซอร์ของแต่ละคน คนที่ใช้เว็บคนละเครื่องหรือคนละเบราว์เซอร์จะมีบันทึกแยกกัน สามารถดาวน์โหลดบันทึกการฝึกเป็นไฟล์สำรองได้จากหน้าความก้าวหน้า

## เผยแพร่ด้วย GitHub Pages

โปรเจกต์นี้เป็นเว็บ static ไม่ต้องใช้ Vercel, ฐานข้อมูล, API key หรือบัญชีผู้ใช้ เมื่อ push การเปลี่ยนแปลงไปที่ `main` GitHub Actions จะสร้างชุดไฟล์เว็บและเผยแพร่ให้อัตโนมัติ

หากเป็นการตั้งค่า Pages ครั้งแรก ให้เปิด **Settings → Pages** ของ repository แล้วเลือก **GitHub Actions** ในส่วน Build and deployment จากนั้นดูสถานะการเผยแพร่ได้ที่แท็บ **Actions**

## พัฒนาบนเครื่อง

ต้องมี Node.js 18 ขึ้นไป:

```sh
npm start
```

เปิด `http://127.0.0.1:4173` เพื่อทดลองเว็บ และใช้คำสั่งนี้ตรวจชุดไฟล์ที่จะเผยแพร่:

```sh
npm run build:pages
npm test
```

เว็บฝึกจำโน้ตใช้การกดเลือกคำตอบ ส่วนเครื่องตั้งสายและแบบฝึกฟังบางส่วนใช้ไมโครโฟนหรือลำโพงของอุปกรณ์ เบราว์เซอร์อาจขออนุญาตใช้ไมโครโฟน
